🎵 Spotify Homepage Clone

A responsive Spotify-inspired homepage clone built using HTML5 and CSS3. This project recreates the look and feel of a modern music streaming platform with a dark-themed interface, navigation sidebar, music cards, artist sections, and a bottom music player.

💻 How to Run
Clone this repository:
git clone https://github.com/yourusername/spotify-homepage-clone.git

Open the project folder:
cd spotify-homepage-clone

Open index.html in your browser.

That's it! 🎉

🌐 Deploy on GitHub Pages
Upload the project to GitHub.
Go to Settings → Pages.
Under Build and deployment, select:
Source: Deploy from a branch
Branch: main
Folder: /root
Click Save.
GitHub will generate a live website URL.
